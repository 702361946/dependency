# `_pygame`

## 职责

该模块对 Pygame 的窗口循环、输入映射、图片、字体、背景音乐和音效进行资源化封装。

## 公共 API

| 类             | 职责               |
|---------------|------------------|
| `Window`      | 创建显示窗口、事件循环、更新回调 |
| `Key`         | 键盘映射注册、移除和执行     |
| `MouseButton` | 鼠标按钮映射           |
| `Image`       | 图片扫描、注册、加载、绘制和缩放 |
| `Font`        | TTF 扫描、字号缓存和文本绘制 |
| `Music`       | 单路背景音乐播放控制       |
| `Sound`       | 多音效加载和播放控制       |

## 资源模型

图片、字体、音乐和音效都使用字典注册资源。资源键通常由相对路径转换而来，目录分隔符被替换为点或自定义分隔符。

```text
资源目录
  └── 扫描文件
      └── 注册路径和逻辑名称
          └── 显式初始化为 Pygame 对象
              └── 播放或绘制
```

## 窗口与事件

`Window` 维护：

- Pygame 显示对象。
- 帧率和时钟。
- 键盘与鼠标映射。
- 用户事件回调。
- 每帧更新函数。
- 主循环退出状态。

## 运行时特征

- `Music` 和 `Sound` 构造时调用 `pygame.mixer.init()`。
- `Image` 构造时调用 `pygame.init()`。
- `Font` 构造时调用 `pygame.font.init()`。
- Windows 默认扫描 `C:\Windows\Fonts`。

这些初始化依赖音频、显示和字体环境，不适合在所有服务器环境直接执行。

## 风险

- 没有自动测试。
- `Music.play()` 在 `name=None` 时可能使用字符串 `"None"` 查找，而不是复用已保存名称。
- `loop` 参数在开始播放后才写回对象，本次播放可能仍使用旧值。
- `Image.add_exclusion_directory(..., del_file=True)` 在遍历字典键时删除元素，可能触发运行时错误。
- `Font.bilt()` 命名疑似拼写错误。
- 多数方法以 `bool` 表示失败，错误细节只保存在日志或异常中。
- 资源扫描和后端初始化耦合，难以单元测试。

## 建议

拆分“资源索引”和“Pygame 后端对象”两层，允许注入音频/显示后端。先为纯路径与映射逻辑增加测试，再用 SDL dummy 驱动覆盖窗口和媒体初始化。
