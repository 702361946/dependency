# 项目概览

## 定位

该项目是一个面向 Python 3.12+ 的个人工具集合，发布名为 `702361946_dependency`，导入名为 `dependency`。目标是把日志、文件格式处理、GUI、Pygame 资源、SQLite 和二维码等常用操作封装成较短的调用流程。

## 当前组成

- 基础层：操作系统信息、工作目录、日志、日志协议和基础 JSON 工具。
- 错误处理：`ReturnValue` 和单子式结果对象 `MEH`。
- 文件操作：路径、原始文件、解释器以及 CSV、INI、JSON、TOML。
- GUI：Tkinter 和 PySide6 两套封装。
- 媒体：Pygame 窗口、事件、图片、字体、音乐和音效。
- 数据与输出：SQLite 和 QRCode。

## 结构特征

- 使用 `src` 布局。
- `dependency` 顶层只默认导出 `_foundation`。
- 功能模块需要从 `dependency.modules._模块名` 单独导入。
- 第三方依赖全部放在 optional dependencies 中，基础安装无强制依赖。
- 模块大量使用包装类和布尔值/结果对象表达操作成功状态。
- 多数模块在导入或实例化时创建日志文件，存在明显运行时副作用。

## 版本现状

| 位置 | 版本 |
| --- | --- |
| `pyproject.toml` 发布版本 | `1.2.4` |
| `dependency.__version__` | `0.2.1` |
| `_foundation.__varsion__` | `0.1.1` |
| 各功能模块 | 独立版本或未声明 |

发布版本、导入版本和模块版本不是同一套版本语义，使用者无法仅通过 `dependency.__version__` 判断已安装发行版版本。

## 总体判断

项目已形成“基础设施 + 可选功能模块”的雏形，文件操作和错误处理具有现有测试支撑。当前主要技术债集中在导入路径、手工打包配置、日志副作用、返回值规范不一致，以及大部分功能模块缺少测试。
